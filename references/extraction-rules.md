# 从乱记录里提决策与行动项

## 一、决策信号词（听到这些，八成拍板了）

| 信号 | 例 | 记成 |
| --- | --- | --- |
| 「就这么定」 | 「那就按 A 方案做，下周开始」 | 决定：采用 A 方案 |
| 「先做 X，Y 放后面」 | 「先上文案版，视觉版下周」 | 决定：拆两次发布 |
| 「不做」 | 「邀请返现这个先砍掉」 | 决定：不做邀请返现 |
| 「按你说的改」 | 「行，按你这个口径重算」 | 决定：采用新口径 |
| 「预算/人力给到」 | 「2 个人可以先给你」 | 决定：批 2 名交付编制 |

**不算决策**：「我觉得可以」「方向上是这样」「回头再看看」——这些进待定项。

## 二、行动项信号词

| 信号 | 例 | 提取 |
| --- | --- | --- |
| 「你去看一下」 | 「张三你看下这个数据」 | 张三：给出数据结论 |
| 「我来」 | 「这个我来改」 | 李四：改完 X |
| 「周X 前给」 | 「周三前把方案发我」 | 期限 = 本周三 |
| 「先拉个群/会」 | 「会后拉个群对一下」 | 责任人：发起人；产物：对接群 + 结论 |

## 三、行动项三要素检查

一条合格的行动项，三个问题都能回答：

1. **谁做？** —— 一个真实姓名。出现「大家 / 产品组 / 相关同学」= 重写。
2. **做什么？** —— 一个可验收的产物（文档/名单/版本/邮件/看板）。出现「跟进/推进/关注」= 重写。
3. **什么时候？** —— 一个具体日期。出现「尽快/下周/回头」= 重写。

**改写示例**

| 原始 | 改写 |
| --- | --- |
| 产品组跟进下小客户的问题 | 张三：输出小客户流失归因表（含 30 个样本），11/3 前 |
| 尽快对齐数据口径 | 李四：拉齐流失率口径并给出复算结果，11/1 前 |
| 大家看看定价方案 | 王五：给出 A/B 两版定价方案与毛利测算，11/5 前交评审 |

## 四、责任人没当场认领怎么办

1. 纪要里标 `⚠️ 待认领`，别自己替他定。
2. 发出时点名：「@张三 这条我记的是你，如果不对今天内说一下。」
3. 24 小时无人认领 → 升级：在群里 @ 会议主持，让他指派。

**不要**写「由产品部负责」——部门不会执行，人才能执行。

## 五、期限怎么推

| 会议里说的 | 纪要里写 |
| --- | --- |
| 「下周」 | 下周一的具体日期（默认下周一，除非说了周几） |
| 「月底」 | 当月最后一天 |
| 「这周内」 | 本周五 |
| 「尽快」 | 问：最晚什么时候？拿不到就用「会议后 3 个工作日」并在纪要里标注"待确认" |
| 「看情况」 | 进待定项，写明"何时必须定" |

**规则**：所有期限写成 `M/D` 或 `M月D日`，不要写相对时间——纪要会被转发，一周后"下周三"就没人知道是哪天。

## 六、该删和该留

| 内容 | 处理 |
| --- | --- |
| 「张三说他觉得…李四不同意…」 | 删。只留最终结论 |
| 讨论了三轮才定的过程 | 删。留一句「因为 X」 |
| 与本次议题无关的插话 | 删 |
| 数据/口径的争议 | 留结论（用了哪个口径），删争论过程 |
| 有人提出的风险 | 留，写进待定或行动项 |
| 明确的截止日期变更 | 留，并注明原日期 |

## 七、纪要发出后的跟进（常被忽略）

- **D+1**：检查待认领是否被认领。
- **到期前一天**：在群里提醒（@责任人 + 一句话）。
- **到期当天没交付**：不问"为什么没做"，问"新的时间点是什么，需要我做什么"。
- **下次会议开场**：先过上次行动项，未完成的必须有新时间点才能过。

> 纪要的成败不在写，在**有没有人回**。发出后 24 小时内没有任何回复，就 @ 三个人各确认一条。
