# 案例：一段语音转写怎么变成一屏纪要

## 用户丢来的原始记录（真实混乱程度）

```
那个…今天主要是想定一下小客户续费的事
张三：我看了下数据，小客户流失有点高，大概六成多？具体数我得再算
李四：我记得上次算的是 58%，但口径不一样，包含了主动终止的
王五（主持）：那这个口径得统一一下，不然没法对外说
张三：行，我这边重新算，用到期客户做分母
王五：好，那就按到期客户口径
李四：定价这块我觉得可以拆个小客户包，比现在便宜点
王五：拆包这个方向可以，但得算一下毛利，别亏
李四：那我出个方案吧，A/B 两版
王五：行，周三前给我看
张三：还有个事，客诉样本一直没人整理，上次说要做的
王五：这个谁来做？…（沉默）…那先记着
李四：对了积分要不要叠加到新包里，财务那边有意见
王五：这个得问财务，先放着
王五：那就这样，大家推进一下
```

## Step 1 · 提决策

**已经拍板的**（有明确"就按这个"）：
- 流失率口径统一为「到期客户作分母」——王五说了"好，那就按到期客户口径"
- 小客户包方向可行，但要先算毛利——"方向可以，但得算一下毛利"
- 李四出 A/B 两版定价方案，周三前

**没拍板的**：
- 客诉样本谁整理（当场问"谁来做"，无人应答）
- 积分是否叠加（要问财务）

## Step 2 · 提行动项（三要素）

| 原始说法 | 提取 | 补什么 |
| --- | --- | --- |
| 张三：我这边重新算，用到期客户做分母 | 张三：按到期客户口径重算小客户流失率 | 缺期限 → 会议后 3 个工作日（11/1），标"待确认" |
| 李四：那我出个方案吧，A/B 两版 | 李四：输出小客户包 A/B 两版定价方案（含毛利测算） | 期限"周三前"→ 11/5（本周三） |
| 客诉样本一直没人整理 | 客诉样本整理 | 责任人空缺 → `⚠️ 待认领` |
| 积分要不要叠加 | — | 不是行动项，是待定项 |

## Step 3 · 待定项

- 积分是否叠加到小客户包｜卡在财务口径｜王五在 11/3 前问财务并给结论
- 客诉样本整理｜卡在责任人未定｜王五在 11/1 前指派

## Step 4 · 一屏纪要

```markdown
# 小客户续费决策会 · 10/30 · 参会 4 人

## 决策
1. 流失率口径统一为「到期客户作分母」（理由：原口径含主动终止，无法对外说）
2. 小客户包方向可行，但须先给出毛利测算
3. 不做：暂不讨论积分叠加，等财务口径

## 行动项
| # | 责任人 | 做什么（含产物） | 期限 |
| --- | --- | --- | --- |
| 1 | 张三 | 按到期客户口径重算小客户流失率，输出复算表 | 11/1 |
| 2 | 李四 | 输出小客户包 A/B 两版定价方案（含毛利测算） | 11/5 |
| 3 | ⚠️ 待认领 | 整理客诉样本 30 条，输出归因表 | 11/5 |

## 待定
- 积分是否叠加到小客户包｜卡在财务口径｜王五 11/3 前给结论
- 客诉样本责任人｜卡在无人认领｜王五 11/1 前指派

## 为什么（一句）
小客户占流失的六成，但定价与口径都没有依据，导致续费改进无法立项。
```

## 对比：如果按原始记录直接发

```
今天开了会，讨论了小客户续费。张三说流失六成多，李四说 58% 口径不同。
王五说口径要统一。李四说可以拆小客户包，王五说要看毛利。张三提了客诉样本。
积分叠加要问财务。大家推进一下。
```

这段话的问题：**没有任何一条能被执行**。谁做什么、什么时候、交付什么，全都没有。这就是「会议纪要」和「聊天记录备份」的差别。

## 这个案例做对了什么

1. **从口语里识别出真决策**：「那就按到期客户口径」是决策，「方向可以」是半决策（所以加上了"须先给毛利"）。
2. **沉默也是信息**：问「谁来做」没人回答 → 记成 `⚠️ 待认领`，而不是替人指派或直接丢掉。
3. **模糊期限被显式标注**：张三没给期限，纪要写「11/1」并注明待确认，而不是留空。
4. **待定项带"卡在什么"**：积分叠加不是"以后再议"，而是"卡在财务口径，王五 11/3 前给结论"。
5. 发出话术里有「有异议今天内回，没异议就按这个执行」——给出沉默即同意的明确期限。
